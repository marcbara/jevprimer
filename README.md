# JevPrimer

A single-page explainer site about Jev, TypeSafe AI's viral "System One Model" (released Sept 15, 2026).

Built with Vite + React + TypeScript + Tailwind CSS v4.

## Dev

```
npm install
npm run dev
```

## Build

```
npm run build
```

Deploys as a static site (Cloudflare Pages / Netlify / Vercel compatible).
Build output: `dist/`
